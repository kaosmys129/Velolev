# B2B 工业品独立站内容规划与价值传达策略 (B2B Website Content Strategy)

本技能提炼自制造企业出海建站的实战方法论，专用于在网站进入视觉设计和前端编码之前，完成**底层产品事实盘点、FAB 价值翻译、Product-Led SEO 架构推导、交互工具页策划、买家五大认知判断闭环与企业实体权威信任构建**。

核心原则：**让真实产品能力和买家任务决定网站页面体系，而非无脑抓取外部关键词拼凑博客；工具可以放大清晰的内容，但不能替企业凭空编造不存在的能力。**

## 二、各阶段核心执行规范与输出交付物

### Phase 1: 底层产品事实盘点与 FAB 价值翻译
1. **任务目标**：跨越“企业自嗨讲参数”与“买家在搜好处”之间的认知鸿沟。
2. **执行动作**：
   - 指导用户团队填写 [产品事实表模板](./templates/product-fact-sheet-template.md)，锁定产品身份、技术属性、场景、商业条件、实证与能力边界六大维度；
   - 依据 [FAB 工业品价值翻译指南](./references/05_fab-value-translation.md)，将参数表逐行翻译为 Feature (功能) -> Advantage (优势) -> Benefit (好处)；
   - 输出完整的 [FAB 工业参数翻译词典](./templates/fab-mapping-dictionary-template.md)。

### Phase 2: 产品资料资产化与 5 级信息架构 (IA) 推导
1. **任务目标**：落实 Product-Led SEO，让真实产品能力推导出站点的页面层级。
2. **执行动作**：
   - 依据 [Product-Led SEO 架构规范](./references/02_product-led-seo.md)，拒绝仅靠文章博客驱动 SEO；
   - 规划 5 级页面矩阵：
     - **Category Hub**：梳理产品线全景与选型逻辑；
     - **Product Detail**：承载核心产品原子化事实；
     - **Solutions & Applications**：覆盖 3 个以上具体施工工况与痛点场景；
     - **Comparison & Selection**：建立与传统方案或竞品的 TCO 成本对比壁垒；
     - **Interactive Tools & Guides**：承载交互计算器与技术 SOP；
   - 填写 [信息架构规划矩阵](./templates/site-ia-matrix-template.md)。

### Phase 3: 决策杠杆交互工具页策划 (Interactive Tools)
1. **任务目标**：在买家采购决策最早期（解决具体工程计算难题时）截流高意向流量。
2. **执行动作**：
   - 依据 [交互工具页规划指南](./references/03_interactive-tool-design.md)，从经济测算型 (ROI/省钱计算器) 或工程兼容型 (法兰/螺栓/选型核查器) 中选择 1–2 款高价值工具；
   - 遵循“前端透明即时计算 + 导出定制分析报告/图纸审核门禁”的低摩擦转化流转规则。

### Phase 4: 产品详情页“五大认知判断”闭环设计
1. **任务目标**：将产品页打造为完成买家认知判断与 AI 问答引用的“信息翻译器”。
2. **执行动作**：
   - 依据 [产品详情页框架规范](./references/04_product-page-framework.md)，自上而下逐一解答买家 5 大疑问：
     1. 这到底是什么产品？（标准品类词标头，拒绝纯代号）
     2. 它适合什么场景？（具体环境与工程工况）
     3. 客户应该怎么选？（选型向导与原生 HTML Key-Value 表格）
     4. 凭什么相信你？（测试条件、真实车间摄影、出厂标定实证）
     5. 下一步怎么做？（三级梯级 CTA 行动点）
   - 诚实罗列“能力边界与负清单”，声明不适用工况。

### Phase 5: About Us 实体确立与出厂信任背书
1. **任务目标**：建立法定 Entity，消除空壳嫌疑，将制造工序翻译为客户交付信任。
2. **执行动作**：
   - 依据 [权威企业实体与信任中枢构建模型](./references/01_entity-trust-model.md)，明确企业法定全称、OEM 制造定位与物理基地职能划分；
   - 梳理出厂四道严苛质检工序（探伤、保压、满载垂直试验台、免熏蒸防震木箱封装）；
   - 执行消极免责语言大扫除：剔除 `pending, unverified` 等自毁语言，将居高临下的“带图纸来”重塑为“24小时免费图纸核对”增值保障；
   - 生成符合规范的 Organization JSON-LD 结构化代码。

### Phase 6: 三级梯度 CTA 转化漏斗与上线门禁审计
1. **任务目标**：对整套内容规划方案实施全方位质量把关，确保高转化率。
2. **执行动作**：
   - 建立顺应买家心理的三级转化梯度（轻度：白皮书/手册；中度：定制 ROI 报告；重度：24h 出厂报价与图纸复核）；
   - 对照 [页面文案规划落地审查清单](./templates/page-copy-spec-checklist.md) 逐页核验；
   - 依据 [建站前内容规划诊断与打分红线](./references/06_content-audit-rubric.md) 进行 100 分制审计，达到 85 分以上方可交付设计与开发。
