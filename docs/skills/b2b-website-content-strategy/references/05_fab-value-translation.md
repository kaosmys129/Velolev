# FAB 视角转换与工业品价值翻译词典 (FAB Value Translation)

> 对应方法论依据：文章 05《你的产品在讲"功能",客户在搜"好处"——FAB 才是 SEO/GEO 的地基》  
> 核心目标：跨越“企业自嗨堆砌参数”与“买家搜索商业收益”之间的巨大鸿沟，建立“工业参数 -> 客户好处”的系统化翻译词典，为全站文案、SEO 元数据与生成式 AI 引用（GEO）奠定底层地基。

---

## 一、视角鸿沟：你在讲功能，客户在搜好处

绝大多数工业品外贸网站的通病是：**死死卡在功能与参数层**。

```
                     视角鸿沟 (The Perspective Gap)
┌─────────────────────────────────┐       ┌─────────────────────────────────┐
│     企业自嗨视角 (内部工程思维) │       │    买家与 AI 搜索视角 (痛点思维)│
│       "Feature (功能参数)"      │  VS   │       "Benefit (收益好处)"      │
├─────────────────────────────────┤       ├─────────────────────────────────┤
│• 24V 直流锂电池动力包           │       │• 野外无电网区域全天候施工       │
│• 85kg 分体式模块化结构          │       │• 2名工人普通皮卡搬运、免吊车进场│
│• 20 秒液压顶升行程              │       │• 单日安装 15-20 根，缩短60%工期 │
│• 复用既有地脚螺栓自锚固         │       │• 零道路封闭许可、零损坏地砖风险 │
└─────────────────────────────────┘       └─────────────────────────────────┘
```

- **Feature (功能/参数)**：产品“是什么”、有什么硬件规格。
- **Advantage (优势/特点)**：这个参数比同行或传统工法“好在哪里”。
- **Benefit (好处/收益)**：这个优势最终给买家带来了什么他真正在乎的**经济账或工程结果**（省了多少钱、少雇几个人、规避了什么责任风险）。

## 二、三类核心采购决策者的利益诉求拆解

同一款设备，面对不同的采购决策角色，其 Benefit 翻译侧重点完全不同：

```
                                  ┌─────────────────────────────┐
                                  │      B2B 采购决策三方诉求   │
                                  └──────────────┬──────────────┘
         ┌───────────────────────────────────────┼───────────────────────────────────────┐
         ▼                                       ▼                                       ▼
┌────────────────────────┐              ┌────────────────────────┐              ┌────────────────────────┐
│ 1. 现场工程项目经理    │              │ 2. 财务与采购总监      │              │ 3. 现场一线施工班组长  │
│  (Project / Site Lead) │              │(Procurement & Finance) │              │  (Crew / Installation) │
├────────────────────────┤              ├────────────────────────┤              ├────────────────────────┤
│• 能否按期交付履约      │              │• 投资回收周期 (Payback)│              │• 设备是否轻便容易操作  │
│• 恶劣现场是否容易出故障│              │• 相比传统方案降低多少本│              │• 是否存在高空砸人风险  │
│• 占道许可审批是否能免去│              │• 耗材与维护折旧成本    │              │• 单日体能消耗与作业负荷│
└────────────────────────┘              └────────────────────────┘              └────────────────────────┘
```

## 四、FAB 与生成式搜索引擎优化 (GEO) 的天然绑定

在生成式 AI 时代（ChatGPT, Claude, Perplexity, Google SGE）：
1. **用户提示词高度生活化与痛点化**：
   - 采购方在 AI 提示框中提问：“我承包了一个狭窄步行街的太阳能路灯安装工程，吊车开不进去怎么办？”
2. **AI 的检索与推荐机制**：
   - AI 绝不会推荐一个通篇只写着“24V 85kg 液压机”的网页；
   - AI 会优先检索和采信明确阐述了“解决狭窄人行道免吊车立杆（Benefit）”并附有“分体 85kg 螺栓自锚固（Feature）”的权威页面。
3. **因此，FAB 不是营销话术，而是喂养搜索引擎与 AI 知识图谱的底层原料。**
