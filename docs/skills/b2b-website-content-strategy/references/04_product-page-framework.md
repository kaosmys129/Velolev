# AI、搜索与买家三友好的产品详情页框架 (Product Page Framework)

> 对应方法论依据：文章 04《一个对 AI、搜索和用户都友好的外贸产品页，应该是什么样的？》  
> 核心目标：彻底告别“一张海报 + 一个参数表 + 一个 PDF 下载链接 + 一个发送询盘按钮”的无效产品页，将产品页打造为完成买家五大认知判断、可被 AI 独立引用事实的“信息翻译器”。

---

## 一、为什么绝大多数外贸产品页无法促成转化？

1. **信息并未辅助买家决策**：页面塞满了制造内部编码和枯燥参数，但买家看完依然不知道：“这东西到底适不适合我的现场？我该选哪款？如果出了质量问题谁来负责？”
2. **隐藏在图片或 PDF 里的“不可检索数据”**：大量关键选型数据被做成了图片横幅或扔在 50MB 的 PDF 目录中，Google 爬虫和 LLM 检索时无法结构化提取，直接沦为“信息盲区”。
3. **充斥无法证伪的形容词**：“High quality, advanced technology, professional service, global leader”，没有任何可验证的实测证据或测试条件支撑。

## 二、买家五大认知判断闭环模型 (The 5-Decision Model)

一个合格的 B2B 工业品产品页，结构上必须顺应买家的心智流动，自上而下逐一解答以下五个问题：

### 判断 1：这到底是什么产品？ (What is this?)
- **标准标题公式**：`[行业通用标准品类词] + [核心差异化特性] + [主要应用场景或额定规格]`
  - ❌ 错误示范：`Model V-85 Heavy Duty Solution`
  - ✅ 正确示范：`12m / 300kg Portable Hydraulic Light Pole Lifter for Crane-Free Road Lighting Installation`
- **首屏副标题 (Subtitle)**：一句话说明它替代了什么、帮助什么角色、解决了什么核心瓶颈。

### 判断 2：它适合什么场景？ (Where does it fit?)
- **具体环境拆解**：严禁写“适用于广泛工业领域”，必须明确列举真实工况：
  - 狭窄人行道与密集绿化带（吊车无法驶入）；
  - 已铺装广场与地下车库通道（重型车轮会压裂昂贵地砖）；
  - 偏远乡村道路与农田电网（远途调度起重机费用远超施工预算）；
- **能力边界与否定列表 (Exclusions)**：
  - 明确标明适用的杆高（≤12m）与额定载荷（≤300kg）；
  - 明确提醒超出范围构件需要大型起重机，体现极高的工程诚实度，反而大幅增强买家信任。

### 判断 3：客户应该怎么选？ (How to choose?)
- **选型逻辑卡片**：给出 3 步选型向导（第 1 步确认杆重与杆高，第 2 步比对法兰对角孔距与地脚螺栓规格，第 3 步确认供电与选配件）。
- **结构化参数表 (Structured HTML Table)**：必须采用原生的 HTML 表格呈现，便于机器爬取与复制，包含：
  - 额定负载 (Rated Load, kg)
  - 适配杆高 (Max Pole Height, m)
  - 分体重量 (Hydraulic Unit / Control Cabinet, kg)
  - 工作电压 (DC Voltage, V)
  - 单充作业次数 (Lifts per Full Charge)
  - 适配螺栓与孔距跨度 (Flange & Bolt Span, mm)

### 判断 4：凭什么相信你？ (Why trust you?)
- **拒绝无凭无据的形容词**，每一项声明后必须附带实证：
  - 宣称“20 秒平稳升起” → 附带“专用 300kg 满载垂直试验台 100% 出厂全检标定实拍”；
  - 宣称“高压防渗漏” → 附带“液压系统保压测试台 24 小时压力降监测数据”；
  - 宣称“结构坚固耐疲劳” → 附带“关键焊缝与铰轴超声波探伤 (NDT) 检验规程”；
  - 宣称“海运零破损” → 附带“650×350×500mm 出口级免熏蒸实木箱与多轴缓冲内衬实拍”。

### 判断 5：下一步怎么做？ (What's next?)
- 杜绝仅留一个空荡荡的 `Submit Message` 按钮。
- **提供梯度明确的行动入口**：
  - 轻度：下载 12m 立杆机技术规格书与施工工法（仅需邮箱）；
  - 中度：使用 ROI 测算器计算本项目的起重机替代节约成本；
  - 深度：提交法兰尺寸或 CAD 图纸，申请 24 小时免费工程师图纸适配核对与出厂报价。

## 三、机器可读性与原子化事实标准 (AI & GEO Ready)

1. **高原子性事实块 (Atomic Fact Chunks)**：
   - 网页中的每一段核心说明都应当具备“脱离上下文依然语义完整”的特点，方便 LLM 在问答引用时作为直接答案源（Direct Answer Reference）。
2. **Product Schema JSON-LD 规范**：
   - 在页面 `<head>` 中注入结构化数据，声明 `name`, `image`, `description`, `category`, `model`, `offers`, `weight`, `dimensions` 等标准属性。
