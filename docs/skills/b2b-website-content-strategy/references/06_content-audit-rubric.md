# 建站前内容规划诊断与打分红线 (Pre-Build Content Audit Rubric)

> 对应方法论依据：`DIAGNOSIS_REPORT.md` 全站深度诊断体系  
> 核心目标：在网站投入视觉设计与前端编码之前，对文案规划草案进行严苛的质量闸口（Quality Gate）审查，防止“先天营养不良”的劣质内容上线。

## 二、逐项量化打分标准与扣分红线

### 维度一：内容定位 (Content Positioning) — 满分 40 分

| 考评项 | 权重 | 满分标准 (8–10分) | 扣分红线 (0–4分) |
| :--- | :--- | :--- | :--- |
| **1.1 采购角色对齐** | 10分 | 区分项目经理、财务总监、施工领班的诉求，页面文案能打动具体角色的核心 KPI。 | 通篇只写“给所有客户提供优质服务”，角色模糊。 |
| **1.2 工况痛点深度** | 10分 | 精准描绘具体作业工况（狭窄绿化带、压碎地砖、吊车进场难、占道审批繁琐）。 | 仅写“适用于各种环境”，无任何工况还原。 |
| **1.3 细分场景与负清单** | 10分 | 明确列举 3 个以上典型细分工况页面，并有明确的“不适用边界（负清单）”。 | 夸大其词声称“万能通用”，无能力边界交代。 |
| **1.4 企业实体与质检** | 10分 | 法定全称、OEM 制造定位、出厂四道质检实景图文、Organization Schema 齐全。 | 充满“待核实、暂无证明材料”等自毁表述，无车间实证。 |

### 维度二：文案表达 (Copywriting Expression) — 满分 30 分

| 考评项 | 权重 | 满分标准 (7–8分) | 扣分红线 (0–3分) |
| :--- | :--- | :--- | :--- |
| **2.1 叙事弧线与心智** | 8分 | 首屏痛点共鸣 → 中段方案与证据 → 尾部低阻力行动，心智流转一气呵成。 | 结构割裂，上来就是干瘪的参数表和冷冰冰的表单。 |
| **2.2 零消极免责语言** | 8分 | 全站清空 `pending, unverified, not approved` 等消极防御语言，转为承诺式服务。 | 盛气凌人命令客户带图纸来，处处甩锅推卸技术责任。 |
| **2.3 严谨与信心平衡** | 7分 | 既有工程参数的实测边界，又有对产品品质与到场即用履约的充分商业自信。 | 要么满嘴跑火车浮夸吹嘘，要么战战兢兢自我贬低。 |
| **2.4 现代工业去八股化** | 7分 | 语言精炼有力，术语准确（M16–M24, ISPM 15, NDT），具备高品质工业美感。 | 充斥外贸翻译腔与空洞形容词堆砌（High quality, top, best）。 |

### 维度三：价值传达 (Value Transmission) — 满分 30 分

| 考评项 | 权重 | 满分标准 (7–8分) | 扣分红线 (0–3分) |
| :--- | :--- | :--- | :--- |
| **3.1 商业 ROI 算账** | 8分 | 具备可交互的 ROI 动态测算工具，给出具体货币节省值与收回投资周期。 | 仅空喊“为您省钱、降低成本”，无具体经济账模型。 |
| **3.2 全周期效率模型** | 8分 | 详细对比准备时间、抬升时间、人员规模、转运便捷度与单日立杆总产量。 | 仅写单次顶升秒数，不交代整体验收与流水线工效。 |
| **3.3 替代对比壁垒** | 7分 | 设立专门对比页（如立杆机 vs 25吨起重机 vs 人工三脚架），形成压倒性壁垒。 | 不敢直面竞品或传统工法，无法回答买家“为什么不租吊车”。 |
| **3.4 三级低摩擦转化** | 7分 | 具备轻度（手册）、中度（测算报告）、重度（图纸核对）三级转化漏斗与保密承诺。 | 只有唯一一个死板的“发送询盘”表单，要求强制传 CAD。 |

## 三、上线前门禁判定规则 (Launch Gate)

- **总分 ≥ 85 分**：**PASS（准予进入设计与开发阶段）**。核心事实清晰，具备强大的说服力与 SEO/GEO 资产价值。
- **70 分 ≤ 总分 < 85 分**：**CONDITIONAL PASS（条件通过）**。需限期整改扣分严重的维度（如补充出厂质检实证或清洗消极免责词）。
- **总分 < 70 分**：**REJECT（否决重做）**。存在重大定位缺失或自嗨八股，禁止进入 UI 界面开发阶段。
