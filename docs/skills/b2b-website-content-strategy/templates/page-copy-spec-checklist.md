# 页面文案规划落地审查清单 (Page Copywriting Spec Checklist)

> 使用说明：在网站文案定稿（Copy Freeze）或交付前端开发前，逐页对照本清单执行终极自查。任何一项出现“否”，均需回退修改。

---

## 一、通用审查红线 (全站强制)

- [ ] **是否已彻底清空消极免责语言**：全站没有任何 `pending verification`, `unsupported`, `do not rely on this document`, `field results pending` 等自毁性词汇。
- [ ] **是否已消除盛气凌人的防御性命令**：没有任何命令客户“必须先带图纸来，否则不予接待”的居高临下文案，全部转换为“免费提供 24h 工程师图纸核对保障”的增值服务承诺。
- [ ] **是否杜绝纯 AI 假图或空洞渲染图**：核心车间、设备装配、出厂质检与施工现场均采用真实高分辨率摄影实拍。
- [ ] **技术参数是否具备原子性**：核心参数已提炼为 HTML Key-Value 键值对，未封死在长图片或不可搜索的 PDF 内部。
- [ ] **是否已配置对应 Schema.org 结构化数据**：首页/关于页注入 `Organization`，产品页注入 `Product`，指南页注入 `HowTo` / `Article`。

---

## 二、首页 (HomePage) 专项自查

- [ ] **Hero 首屏是否遵循 FAB 架构**：标题是否明确指出核心 Benefit（如免吊车立杆、节省 70% 成本），副标题是否说明 Feature，避免空洞的“欢迎来到某某官网”。
- [ ] **四大核心事实指标带**：首屏下方是否有 4 个关键工程指标（如额定载荷、适用杆高、分体自重、单充续航），建立专业工业厚重感。
- [ ] **痛点共鸣与场景入口**：是否生动描绘了狭窄步道、压碎地砖、吊车租赁繁琐等施工现场真实痛点。
- [ ] **实体车间背书透传**：是否向访客直观展示了加工中心、焊接工装或装配现场实景，证明源头制造能力。
- [ ] **行动引导梯度**：除“立即询价”外，是否提供了“测算 ROI 收益”或“核对法兰孔距”等低心理门槛的次级行动点。

---

## 三、产品详情页 (ProductPage) 专项自查

- [ ] **品类命名是否标准**：采用“标准品类词 + 核心差异 + 适用工况”，严禁仅写内部产品代号。
- [ ] **买家五大认知判断是否闭环**：
  - [ ] 1. 一句话看懂这是什么？
  - [ ] 2. 清楚交代适合哪些工况环境？
  - [ ] 3. 给出清晰直观的 3 步选型逻辑与结构化参数表？
  - [ ] 4. 具备探伤、保压、300kg 试验台等可验证的真实质检证据？
  - [ ] 5. 提供低门槛的下一步行动指引？
- [ ] **能力边界与负清单**：是否诚实交代了最大作业极限（如超重超高必须用吊车），建立专业诚实信任。

---

## 四、关于我们页 (AboutUsPage) 专项自查

- [ ] **法定实体全称与品牌**：是否明确标明公司注册实体名称与行业专长定位。
- [ ] **物理职能清晰拆解**：是否清晰交代了总部研发、生产制造基地、检测中心与出口物流各自的真实分工。
- [ ] **出厂四步质检工序实证**：是否完整呈现了探伤（NDT）、保压防渗漏、满载垂直试验台标定、免熏蒸防震木箱包装图文实证。
- [ ] **商业保密与询盘承诺**：是否明确做出“图纸严格商业保密，未授权绝不外泄”的客户承诺。

---

## 五、交互工具页 (Tools) 专项自查

- [ ] **计算逻辑是否透明即时**：滑块或输入框改变时，数字是否在前端实时跳动计算，严禁输入前强制锁死要求填邮箱。
- [ ] **多地域预设与自定义**：计算器是否预设了北美、西欧、亚太等不同地区的基准工况参数，并允许用户自由调整。
- [ ] **转化承接自然顺畅**：测算完毕后，是否支持“一键导出定制项目分析 PDF 报告”或“将数据一键带入询盘表单”。
