## 3. 当前发现

[about-copy.json](/Users/peterpc/Documents/liftpolemachine-web/maquin-astro-theme/src/data/about-copy.json:10)出现年装配500+台、实体一体化工厂、2015–2018起的发展历程、逐台300kg满载测试及24小时零泄漏/零压力衰减。现有事实台账没有这些企业能力、历史或测试记录，业务/工程门槛也仍为pending。

300kg是S4的额定载荷，不能据此认定每台设备完成300kg测试。时间轴还把180–260mm直接解释为通用螺栓圆适配，而原基线保留了图示术语待工程复核。应提供对应的一手证据并登记审核，或把未经确认的断言退回待核验表达；七语应同步处理。
