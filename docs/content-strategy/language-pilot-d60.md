# D60 语言试点准备

> 历史阶段记录：2026-10-29已完成六语17页核心内容的本地重构与自动验收。当前进度见 [六语重构交付](2026-10-29-multilingual-reconstruction.md)。下述“未翻译”及30条CSV任务保留为D60当时的准备状态；专业母语审校仍待完成。

当前只完成英语母版开发与本地自动验收；没有将现存七语页面标为已通过专业母语审校。保留六个语言前缀与现有可用路由，不生成缺少译文的英语替身。

`language-pilot-d60.csv`列出FR、ES及备选ID各10页，共30条审核任务。FR/ES是原计划建议的首批组合；ID只有在实际销售线索、当地合作与审校资源支持时替换ES，不是已验证的国家市场排序。每轮最多两个语言包。

首批主题为首页、产品、适配、对比、ROI、两场景、资料、FAQ和报价。CSV区分现有路由与规划目标：规划目标没有公开、没有加入hreflang，也不因一行任务记录而产生页面。现有译页仍是基线约束的旧内容，尚不能视为新英语母版的完整译稿。

按此顺序处理：确认英语事实及适用边界→完成对应译稿→核对术语与数字/单位→母语采购表达审核→技术审核→表单/下载/工具本地化→移动端与链接验收→批准对应关系→按批发布。站点不通过自动回退英语来填补缺译。

需要真实指派母语与技术审核人，并核对原31条术语草案。场景装配、主体资料和操作文档仍待证据时，同步保留限制，不能在译文中升级为已验证结论。法语、葡语或西语并不自动等于某个单一国家的法规、成本和采购习惯。

当前没有GSC、GA4或CRM数据，语言与国家的经营优先级仍待验证。D61+应根据实际采购疑问和有效线索调整试点，不倒填搜索量、流量或询盘数量。
