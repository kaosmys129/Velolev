## 当前维护规则

`npm run build`仍生成静态页面，同时记录 `.volvet-build.json`。修改源码或参考媒体后，必须先重建再验证。浏览器检查在开始时锁定构建摘要，并在结束时核对工作区没有变化；固化清单也记录参考媒体的逐文件摘要。该记录用于本地验收追溯，不是产品或工厂认证。

当前路径和下载接口保持可用，GEOFlow真实历史稿仍未自动公开。七语新文案属于待专业母语审核稿；没有填写虚构审核人或将发布门槛改为approved。
