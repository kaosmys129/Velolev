# 六语采购站重构与旧主题剥离评估

本次目标：完成剩余 VI、TH、ID 的17页核心内容重构，补齐 ES、FR、PT 与其共用的交互和资料本地化，再基于实际引用评估旧 WordPress 主题的可剥离部分。评估不等于直接删除文件，不部署正式站点。

验收清单：

- [x] 六个小语种均有17个核心主题，与英语共用采购组件、导航、媒体及响应式布局。
- [x] 完整译稿、可访问性文案、动态提示、ROI 结果带入询盘、本地下载资料与视频字幕。
- [x] 旧核心路径有效迁移；语言切换保留主题；元数据与语言对应只指向真实页面。
- [x] 七语事实、关键规格与证据边界保持一致，联系方式继续待配置；人工专业译审不冒充已完成。
- [x] 当前源码与构建一致；页面、链接、静态资源、窄屏、图库、清单、ROI、私有收件行为通过验收。
- [x] 完成旧主题引用及体积盘点，区分可直接剥离、需替换后剥离和应保留，给出迁移顺序与回归条件。

实施范围以当前源码和构建为准。旧 D60 语言试点表属于当时的准备记录，不能作为本次完成证明。本次交付及验收结果列于下文。

六语合计102页，连同英语17页共119个核心页。相比本次启动时，新增完成45个页面对齐。每语种覆盖首页、产品、适配、两个方案、对比、ROI、方法指南、资料、FAQ、关于、指南索引、报价、联系和三份政策页。

VI/TH/ID新增完整684项基础词库，并接入共同的动态与资料文案。翻译在构建期完成，没有增加浏览器翻译库或外部翻译请求。首页采用与英语相同的样式加载方式；内页复用同一套组件。专业母语译审状态继续为pending，自动检查不等于母语批准。

页眉聚合下拉、页脚、语言菜单和CTA全部指向真实本语种页面。语言切换保留当前主题。原产品与报价URL保留，其他旧别名由统一路由表转向本语种当前目标，HTTP跳转保留查询参数；配置夹具中检查自引用canonical、互相对应的hreflang及sitemap。

ROI结果、错误提示与摘要按语言显示，摘要区分两种方法的输入值。访客选择带入后才在本标签页短暂存储，报价备注可编辑；过期内容不带入，读取后移除存储，最后提交才进入私有数据库。服务器字段错误也显示对应语言提示。

每语种有3份真实本地化下载，共18份，含规格CSV、规格JSON与空白项目资料CSV；英语原3份保留。JSON保留稳定的机器字段及规格数值，同时提供本语言标签与限制说明。视频新增6份四段字幕并按页面语言加载，共7语字幕，不把参考图视频描述成现场操作证据。

## 验证结果

- 六语102页静态检查533项通过；配置origin夹具的对应检查533项通过。
- 七语浏览器验收1406项通过，覆盖17页在1440/390/320px的布局、导航、图库、清单、视频字幕、ROI、错误提示、实际测试收件及下载。无浏览器脚本错误、无本地页面或资源HTTP错误。
- 既有D30采购回归81项及D60页面/工具回归142项通过。受控收件均标记测试，不计作经营线索，未发送外部邮件。
- 内容政策、决策与本地化单测、询盘服务测试合计40项通过。事实基线、三种构建模式、元数据与内容检查保留对应报告。

精确源码/媒体摘要、页面与下载校验和、最终证据索引见 [本次验收清单](multilingual-reconstruction-verification.json)。当前页面库存见 [六语库存CSV](page-inventory-multilingual.csv)。运行 `npm run locales:check` 和 `npm run locales:browser` 可以复验。
