## 收件闭环

`POST /api/inquiries`验证资料后，将询盘和可选附件原子保存到私有SQLite数据库；保存成功才返回VOL回执编号。没有模拟成功，也没有将回执写成“邮件已发”。可选参数允许未知留空；附件限制为PDF/JPG/PNG、5 MiB。

前端提交期间防止重复点击，响应失败保留本页数据，重试沿用请求标识；相同内容重试不会多记一条询盘。服务端处理字段错误、无效附件、跨站请求、限流及存储异常。私有管理界面提供密钥鉴权、列表/详情、附件下载、处理状态、分页、测试记录筛选和CSV导出。数据库、附件与密钥不进入public、dist或Git。

受控浏览器测试使用独立数据库，每条记录为 `isTest=true`，默认经营列表和CSV排除这些记录。本次七语真实保存仅证明本地服务链路可用，不是实际客户询盘，不构成邮箱投递、CRM接入或生产环境验收。完整启动、密钥保管与备份步骤见 `maquin-astro-theme/INQUIRY_OPERATIONS.md`。

## URL与内容一致性

| 事项 | 当前结果 |
|---|---|
| canonical | 读取实际页面路径，修复文章详情误用列表路径；不再以共享路由对象的slug决定详情canonical |
| hreflang | 核心页对应关系来自真实路由注册；英语指向新采购页，其他语言保留真实现存页；未制作译页不补空URL |
| 本地301 | `/equipment/`、`/equipment-detail/`直接到新产品；`/pricing-plan/`到`/quote/`；`/en/`到根目录 |
| 静态托管边界 | Astro别名文件为静态跳转；实际HTTP 301由本次Node服务提供；生产换平台必须配置同等301 |
| 预览索引 | 未配正式域名，仍noindex、robots禁止抓取，无正式canonical/sitemap |
| 已配置域名测试 | 仅在临时输出目录使用保留测试origin `https://example.test`，验证canonical、互链和sitemap；没有改变正式域名配置 |
| 产品与商务事实 | S4规格不变；M24不默认随附；20秒、>50、>3000保持厂家标称且实测待补；无公开价格/库存/Offer或固定回本承诺 |

当前构建共110个公共HTML：109个内容路由和1个404，排除别名和后台。这是本地构建范围；本次完整重构8个英语核心页，并替换6个其他语言联系表单，不把历史119套片段、全部110个HTML或现有译稿计为新完成内容。
