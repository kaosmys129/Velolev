# 机械类网站设计参考包

先打开 `index.html` 浏览 9 页视觉规范，或阅读 PDF。完整开发上下文见 `DESIGN-SPEC.md`。

`mechanical-b2b-starter.css` 是可复用基础样式；`site-current-procurement.css` 是当前网站完整 CSS 的追溯快照。两者不要同时加载。

`design-tokens.json` 明确区分当前数值、局部覆盖和迁移建议。新项目需单独提供品牌、产品参数、图库、语言包和业务服务。本包不包含本站字体文件、后台或客户资料。
