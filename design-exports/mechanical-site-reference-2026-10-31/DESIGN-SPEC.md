# 机械类 B2B 网站设计规范与复用指南

版本：2026.10.31。参考站点：volvet 便携式立杆设备网站。导出范围：2026-10-31 本地工作区当前代码，包含尚未提交的组件更新。来源提交基点为 `4fe60c7`；每个来源文件的实际摘要见 `source-manifest.json`。

本手册供机械、施工装备、液压设备、工厂自动化及其他工业品网站参考。设计语言可以复用，产品参数、品牌标识、资质、工厂图片和商业承诺必须换成新项目自己的内容。

## 1. 设计定位

**精密工业、纸色底板、参数驱动、证据可查。**

核心识别来自暖米背景、深色工程文字、工业黄色行动按钮、灰绿产品展台、细线结构和充足留白。产品图是视觉主体；工程编号与规格数据建立秩序；操作入口承担转化，不依赖大面积装饰徽章。

- 适合：单一或少量核心产品、需要图纸匹配、方案比较、B2B 询价的设备制造商。
- 多产品线项目：保留产品分类、筛选、机型对比能力，不把本站的单产品结构直接用于数百 SKU。
- 一屏一个主要动作：看设备、核对选型、申请报价中选一个作为主按钮。
- 内容卡片以 1px 分割线构成层级，通常使用 0-2px 微圆角；投影主要留给机械主体和浮层。
- 每个模块共享容器、字体、色彩和标题层级；允许因内容角色做局部覆盖，不另起一套圆角和色板。

## 3. 字体、字阶与数字

当前全站正文：`Geologica, 'Trebuchet MS', sans-serif`。工程编号常使用 `'Courier New', monospace`。本地 Geologica 字体为 Latin 子集；中文、泰文等页面应有合适的字体回退或独立字体配置。

| 角色 | 当前字号 | 字重 | 当前行高 / 字距 |
| --- | --- | --- | --- |
| 首页主标题 | `clamp(40px, 5.7vw, 82px)` | 650 | 1.08 / -0.045em |
| 一般页面 H1 | `clamp(36px, 5vw, 64px)` | 650 | 继承全局 1.08 / -0.045em |
| 模块 H2 | `clamp(30px, 3.6vw, 50px)` | 650 | 全局 1.08 / -0.045em |
| 一般 H3 | 23px | 650 | 全局 1.08；多数组件覆盖到 1.25 / -0.025em |
| About 主标题 | `clamp(34px, 4.8vw, 62px)` | 650 | 1.12 / -0.035em |
| 质检卡片标题 | 19px | 650 | 1.3 |
| 导语 | 桌面 18px / 手机 16px | 400 | 1.7 |
| 正文 | 15px | 400 | 1.65 |
| 规格数字 | 桌面 36px / 手机 30px | 继承上下文 | 1.2 / -0.05em |

## 4. 容器、网格和留白

### 4.1 当前容器与区块

- 内容上限：1240px；大屏 `.wrap` 为 `min(1240px, calc(100% - 96px))`。
- 宽度 ≤1050px：容器变为 `calc(100% - 60px)`，左右各 30px。
- 宽度 ≤760px：容器变为 `calc(100% - 36px)`，左右各 18px。
- 通用区块：桌面上下各 90px，手机上下各 55px。
- 通用双列间距：70px → 40px → 30px；手机转单列。
- 首页 Hero：1.05fr 文案 / 0.95fr 设备图，桌面列距 50px；主图底板至少 515px 高，52px 线网格。
- 参数带：桌面 4 列，手机 2×2；桌面单元格 padding 26px 32px，手机为 20px。
- 常用局部间距：12、16、18、20、24、25、28、30、32、35、40、45、50、55、60、65、70、90px。本站没有统一强制的 8px 倍数系统，不应把现状误写成严格 8pt 网格。

### 4.2 当前导航的最终覆盖规则

页头最大宽 1440px。大屏最终布局为品牌 / 导航 / 语言操作三列；大屏最终横向 padding 为 36px。≤1280px 折叠导航，语言按钮仍可见；折叠页头为 20px 24px；≤600px 再变为 18px。CSS 中虽然保留了更早的 1100px 和 760px 规则，但最终行为要按级联后的 1280px 导航规则判断。

### 4.3 响应式与验收宽度

| 宽度 | 当前主要行为 |
| --- | --- |
| ≤1280px | 页头菜单折叠，语言选择不藏入菜单 |
| ≤1050px | 容器收紧，部分 4 列模块变 2 列 |
| ≤800px | ROI、FAQ 等布局转单列 |
| ≤760px | Hero 与通用双列转单列；主要移动端规格生效 |
| ≤600px | 页头与询盘表单收紧 |
| ≤480px | 部分工具字段、质检网格进一步转单列 |
| ≤360px | 特小屏工具选项与 KPI 布局调整 |

推荐至少检查 1440、820、390、320px。390 和 1440 是测试视口，不应误标为所有组件都使用的媒体查询断点。

## 5. 核心组件规格

### 5.1 按钮与文字链接

主按钮：黄底、深色字、2px 圆角、1px 透明边框、`padding:17px 23px`、字重 600，内容与右侧箭头使用 flex 排列。hover 使用 `#ffdb59` 并上移 2px，过渡 0.15s。小按钮 padding 12px 17px、13px 字号。次要行动用带底线的文字链接，避免同屏堆满同权重的黄按钮。

当前按钮没有固定 54px 高度。一般在 15px 正文及 1.65 行高的上下文中，单行高度约为 60.75px；字体、换行、局部字号都会改变最终高度。复用应保证触控面积，而不是锁死高度。

### 5.2 表单

输入最小高 48px，白底、2px 圆角，询盘输入 padding 13px 14px；桌面两列、手机单列。只把必要联系方式和项目目的设为早期输入；图纸、尺寸和额外说明可收在展开区域。标签必须常驻，不能只用 placeholder。错误用 `aria-invalid` 加文字说明，输入值保留，展开区域中的错误字段应自动可见。

### 5.3 图片与设备展台

透明底设备图以 `contain` 展示，保留结构完整；场景与工厂照片使用 `cover`。通用照片为 3:2，质检与画廊常用 16:10，视频 16:9。图注与标签说明图片角色，放大按钮通常 44px。主图可用轻投影；常规内容卡片不需要浮起式大阴影。

### 5.4 表格、规格条和四维比较

型号与配置使用键值表；数值与单位相邻，不只写“高效率”等抽象词。比较表使用真实行标题/列标题，宽表由自身容器滚动，禁止让整页产生横向溢出。当前比较表最小宽 560px；手机仍保持语义表格，不复制出另一份隐藏卡片内容。

### 5.5 采购入口

三个阶段为：下载资料 → 核对底座 / 图纸 → 项目询价。使用 01/02/03 工程编号、贯穿分割线及不同主次行动。默认只突出当前最适合的入口。下载应直接拿到实际文件；没有成品白皮书时不显示“立即下载白皮书”。

### 5.6 工具与结果面板

左侧输入 / 右侧结果，手机改纵向。使用当前输入计算，区分未填、有效、需补件、需审核与无效输入。法兰工具不得仅凭两个尺寸输出实际作业批准；ROI 展示假设、公式、单位及正/负结果。改变输入后清除过期结果，重置按钮清除旧状态；通过用户点击才把选型信息带入询盘。

### 5.7 About、质检与证据

四步质检可使用 4 → 2 → 1 列网格、图像、编号、简短标题与说明；工厂、计量、团队、物流承担各自信息职责。图像展示和企业资质声明要与实际资料相符。可验证记录优先于无出处的客户数字、徽章与工厂历史。

## 6. 页面结构参考

| 页面 | 建议顺序 | 主要任务 |
| --- | --- | --- |
| 首页 | 用途与主图 → 四项规格 → 工况 → 结构/价值 → 信任 → 下一步 | 快速认识并分流 |
| 产品详情 | 产品身份 → 图库 → 技术表 → 配置 → 选型边界 → 包装 → 询价 | 完成采购判断 |
| 应用方案 | 场景限制 → 工作范围 → 设备适配 → 项目资料 → 技术入口 | 将场景转为选型 |
| 工具页 | 输入依据 → 工具 → 结果 → 假设/公式 → 带入询盘 | 完成可执行任务 |
| About | 明确实体和产品焦点 → 工厂资料 → 质检 → 技术支持 → 交付信息 | 建立可信度 |
| 资料页 | 实际文件 → 版本/格式 → 适用范围 → 补充资料入口 | 降低评估成本 |
| 询价页 | 任务说明 → 联系/项目表单 → 提交凭证 → 后续流程 | 保存有效请求 |

新项目参数条换成其品类最关心的 4 项，如额定载荷/行程/电源/重量，或加工范围/主轴功率/精度/占地。不得把本站 12m、300kg、24V 等产品参数当成通用行业数据。

## 7. 交互、可访问性与动效

全局键盘焦点为 3px `#947500`，通常 offset 5px；部分表单有自己的 focus 覆盖规则。按钮、选择器、菜单具有可感知的状态与足够点击范围。菜单标注 `aria-expanded`，当前页面用 `aria-current`；图片灯箱支持 Escape、焦点返回；结果区域使用 `aria-live`。不能只靠黄/绿/红判断结果。

基础按钮动效为 0.15s，图片和局部组件约 0.2-0.6s。产品放大、页面入场均服务内容识别；`prefers-reduced-motion:reduce` 关闭动画与过渡。浮层与阴影可用于明确功能目的，不需把所有圆形图标或阴影都视为禁用项。

## 8. 多语言规范

当前支持 en、es、fr、pt、vi、th、id。所有语言共用结构与媒体，文案来自独立词典。布局须接受文字增长，禁止依赖英文字符宽度硬写高度。中文和泰文应特别检查字体字形、断行与字距。

必须覆盖：正文、按钮、菜单、alt、aria-label、图注、输入错误、工具状态、KPI 单位、下载链接、询价路径和 FAQ JSON-LD。构建时正文翻译不能自动翻译浏览器脚本；交互应读取当前语言的运行时词典。子组件显式传入 `locale`，不要依赖默认英文。格式化数字使用当前语言，机器存储使用稳定数值与单位。

上线前执行缺译、模板占位符、内部路径、同页语言切换和实际交互检查。本规范导出的是规则，不等于为新项目准备好了七种语言成品文案。

## 9. 可迁移与需替换的部分

| 可沿用 | 应按新项目调整 |
| --- | --- |
| 语义色角色、细线结构、留白方法 | 品牌主色、名称、Logo、字体文件 |
| 产品图 + 参数带的首屏逻辑 | 产品照片、尺寸、承载、功率等实际参数 |
| 资料/选型/询价的分层入口 | 样本、图纸、报价和交付流程 |
| 比较与计算工具的输入-结果模型 | 计算公式、法规条件、工程判断范围 |
| 多语言组件与词典契约 | 语种、翻译、当地业务用语 |
| 工厂与质检的信息组织方式 | 企业实体、工厂事实、认证和记录 |

不建议直接沿用：用于软件订阅的套餐卡片、满屏同权重徽章、没有图片证据的绝对安全承诺、固定行高导致的多语言裁切，以及只有视觉没有可用资料的下载按钮。

## 10. 给其他建站项目的指令模板

> 请参考附件中的机械类 B2B 设计系统建立网站。采用暖米底色、深墨文字、品牌主色行动按钮、灰绿或中性产品展台、细线分割与工程编号。以设备图、核心规格、适用工况、配置比较和可信资料作为主要内容。复用容器和组件节奏，同时根据本品牌、产品线数量及实际图文调整信息架构。正文和交互文案使用统一语言词典，下载与询价保留当前语言。页面在 1440/820/390/320px 下无整页溢出，键盘操作和减少动画偏好可用。所有参数、图片、案例、资质和商业条件来自本项目资料。优先使用 mechanical-b2b-starter.css 和 design-tokens.json；site-current-procurement.css 仅供追溯本站完整实现。

项目补充项：品牌与主色、设备品类与机型数量、目标客户、四项关键参数、必需语种、真实图片、资料下载、询盘字段、部署要求。

## 11. 包内文件

- `index.html`：9 页视觉规范，浏览器直接打开，可查看组件和响应式样例。
- `mechanical-website-design-standard.pdf`：便于分享与打印的同版视觉手册。
- `DESIGN-SPEC.md`：本详细说明，可作为其他项目的建站上下文。
- `design-tokens.json`：当前值、局部覆盖及迁移建议。
- `mechanical-b2b-starter.css`：可复用基础样式，不含本站业务逻辑。
- `site-current-procurement.css`：当前全站 CSS 快照，包含历史级联覆盖。
- `assets/`：当前本地站点截图及浏览器实测值，只作设计参考。
- `source-manifest.json`：来源文件及 SHA-256 摘要，区分当前工作区与提交版本。

浏览器可交互示例用于观察按钮、焦点和输入样式，不接收项目咨询或提交业务数据。CSS starter 是轻量起点，不是带 CMS、后台、语言词典和询盘服务的成品网站。
