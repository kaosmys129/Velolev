# 渐进式大纲人机协同与原子事实挂载架构

## 1. 为什么坚决推行 Outline-First？

在传统工作流中，运营人员直接输入“写一篇 2000 字路灯立杆机文章”，大模型会一次性盲写。这会导致两大致命问题：
1. **工程逻辑颠倒**：未讲清工况约束就直接给结论，或者技术参数自相矛盾；
2. **AI 幻觉失控**：大模型随意编造“500kg 承重”、“单人 2 分钟搞定”、“德国制造认证”等严重违规内容。

**渐进式大纲管线将生产拆分为两步**：
* **第一步（大纲规划）**：输出 4–6 个 H2 骨架，并为每个小节显式绑定原子事实台账编号（F001–F031）与转化漏斗标签；
* **第二步（正文扩写）**：大纲经人工复核或评审 Agent 校验逻辑连贯性后，大模型仅被允许在大纲框架与事实边界内展开行文。

## 2. 核心原子事实台账清单 (F001 - F031)

| 事实编号 | 核心物理参数 / 规范事实 | 行文红线要求 |
|---|---|---|
| **F001** | 分体双模块机械架构（液压升降机 + 电气动力柜） | 必须说明为两名作业人员搬运与组装，严禁称“单人操作” |
| **F002** | 额定垂直举升载荷严格为 **300 kg** | 严禁标称 350kg/500kg 等虚标数据；说明经出厂垂直试验台核定 |
| **F003** | 最大适配灯杆高度为 **12 米** | 覆盖 6m 至 12m 市政标准路灯与太阳能路灯杆 |
| **F004** | 动力源为集成式 **24V DC 直流电池系统** | 无需三相交流电、无需燃油发电机，无废气排放 |
| **F005** | 液压垂直有效行程 **800 mm** | 配备机械安全自锁销，防止液压失压意外下坠 |
| **F006** | 伸缩立柱材质为高强结构合金 | 确保抗侧向倾覆刚度与最小挠度变形 |
| **F007** | 具备多点可调液压支腿与水平气泡指示器 | 适应不平整路肩、硬化沥青或坚实砂石路面 |
| **F008** | 分体总重量严格为 **85 kg** | 子模块单个重量小于 45kg，符合职业健康搬运标准 |
| **F009** | 装箱外形尺寸 **650 × 350 × 500 mm** | 可直接放入标准皮卡后斗或工程厢式货车 |
| **F010** | 完全免除市政道路封路审批与重型吊车入场许可 | 突出狭窄巷道、步行街、园区内部路段施工优势 |
| **F015** | 通用底板适配地脚螺栓分布圆直径（P.C.D.）**180 mm 至 260 mm** | 采用长圆腰孔设计，兼容四螺栓主流方形或圆形基础法兰 |
| **F016** | 基础螺栓适配孔径容纳 **M16 至 M24** 规格锚栓 | 满足绝大多数路灯基础笼地脚预埋螺栓规格 |
| **F020** | 100% 出厂前液压 24 小时保压测试与 300kg 垂直试验台核定 | 强调工厂级出厂检测与工程安全裕度 |
| **F025** | 出口采用重型钢带加固木箱包装（符合 ISPM-15 规范） | 确保海运集装箱多式联运抗颠簸与防潮防护 |

## 3. 大纲小节与漏斗属性绑定示例

```markdown
## Section 1: Jobsite Logistics: Why Heavy Cranes Fail in Narrow Access Poles
- 论点：市区步道、太阳能园区与住宅狭窄路段吊车进场难题
- 绑定事实：F010 (免除市政封路审批)
- 转化属性：none
- 引用标准：OSHA 1926 Subpart CC

## Section 2: 24V Modular Hydraulic Engineering: Replacing 16-Ton Machinery
- 论点：双分体模块装卸、24V 电池无电作业、12米杆高覆盖能力
- 绑定事实：F001, F003, F004, F008
- 转化属性：mid (嵌入 ROI 计算器测算卡片)
- 引用标准：EN 40-3

## Section 3: Jobsite Safety & Structural Stability: 300kg Tested Load Capacity
- 论点：垂直试验台严格标定、多支腿水平防倾覆、彻底规避高压触电危险
- 绑定事实：F002, F007, F020
- 转化属性：none
- 引用标准：OSHA 1926 Subpart CC

## Section 4: Universal Base Flange Integration: P.C.D. 180mm to 260mm
- 论点：长孔腰槽底板对齐、M16-M24 螺栓规格兼容、快速法兰对中
- 绑定事实：F015, F016
- 转化属性：bottom (嵌入 24h 免费底板图纸审核与私密报价)
- 引用标准：ASTM F1554 / ASTM A325

## Section 5: Step-by-Step Two-Person Installation Workflow
- 论点：皮卡后斗卸料、10分钟现场机械销紧固、平稳垂直顶升与地脚紧固
- 绑定事实：F001, F005, F009
- 转化属性：top (嵌入产品规格书与现场安装手册 PDF 下载)
- 引用标准：ANSI/IES RP-8-18
```
