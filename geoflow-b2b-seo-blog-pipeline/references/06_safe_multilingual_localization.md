# 事实保真型多语言本地化与 Astro 审核门禁

## 1. 破除“纯 AI 批量机翻”陷阱

很多外贸独立站运营设想：“每天用 AI 写 1 篇英文，然后一键机翻成西语、法语、阿语、泰语、印尼语等 6 个小语种，全自动发布”。
**在机械工业出海领域，这种做法会导致灾难性后果**：
1. **Google Helpful Content 算法降权**：毫无修改的机械复制被直接判定为 Scaled Content Abuse；
2. **专业机械工程术语失真**：
   - “地脚螺栓分布圆直径 P.C.D.” 被误翻成日常圆圈词汇；
   - “分体总成” 被误翻为断开损坏；
   - “液压顶升行程” 被误翻为普通千斤顶垫高；
   海外 EPC 承包商一旦看到粗劣译法，会立即判定企业不具备工业制造能力；
3. **参数漂移与法律风险**：机翻极易在英制与公制单位换算（如米转英尺、千克转磅）中产生数值幻觉，引发起重安全事故与海外法律诉讼。

## 3. GEOFlow 后台持久化与人工审核操作 SOP

### 1. 自动化入库与同步
流水线脚本调用本地 GEOFlow 服务 API（运行在 `http://127.0.0.1:18082`）持久化写入文章：
```bash
# 全量同步所有草稿
npm run geoflow:sync -- --all

# 或同步指定主题的所有多语种文章
npm run geoflow:sync -- --topic portable-light-pole-lifter-explainer
```

### 2. 入库状态与权限硬锁定
- **状态强制隔离**：所有自动化入库的文章必须标记为 `status = 'draft'` 与 `review_status = 'pending'`，严禁直接设为 `published`；
- **图片挂载校验**：文章内引用的配图通过容器内部映射 `/var/www/html/public/images` 提供服务，HTTP 访问响应必须为 `200 OK`；
- **API Token 鉴权**：使用 `ops/geoflow/private/api-token.json` 中的 Bearer Token，必须具备 `articles:read` 与 `articles:write` 权限。

### 3. 管理员集中审核工作台 (GEOFlow Admin)
- 登录访问：`http://127.0.0.1:18082/geo_admin/articles`；
- 审核人职责清单：
  * [x] **配图完整性**：确认篇首 16:9 Hero 卡、正文 4 张架构/法兰/SOP/吊车对比图均能正常清晰展示；
  * [x] **图注与翻译**：核验小语种工程术语（P.C.D.、分体模组等）无变形、图注参数准确；
  * [x] **内链可用性**：核验站内 CTA 与链接锚文本是否精准有效；
  * [x] **事实一致性**：确认无单人宣称、无虚构认证、无货币符号。

## 4. Astro 自动化门禁质检标准

在内容正式进入静态生产发布前，必须通过 `maquin-astro-theme` 的门禁脚本验证：

```bash
# 1. 从 GEOFlow 导出待发布候选稿
node ops/geoflow/runtime/manage.mjs export-reviewed --output=review-export.json

# 2. 预处理候选稿并自动提取事实编号与内链
node maquin-astro-theme/scripts/prepare-geoflow-review.mjs --input=review-export.json --output=review-candidates.json

# 3. 审核人在 review-candidates.json 中完成签核确认 (status: "approved")

# 4. 导入静态发布数据源
node maquin-astro-theme/scripts/import-reviewed-content.mjs --input=review-candidates.json --apply

# 5. 执行全站 D30/D60 门禁全量构建断言
npm test
```

### 门禁强制断言清单：
* [x] **物理事实不容篡改**：载荷必须为 300kg，杆高必须为 12m，分体自重必须为 85kg；
* [x] **事实台账至少绑定 1 项**：`evidenceRefs` 必须包含合法的 `F001`–`F031` 编号；
* [x] **关联路径必须存在**：`relatedPaths` 必须全部为已批准的核心页面；
* [x] **零容忍商业违禁词**：全站坚决过滤 `CE certified`, `ISO certified`, `guaranteed payback`, `one-person operation`, 旧品牌名及外币符号；
* [x] **内容 SHA-256 签名完全匹配**：内容发生任何一个字符篡改，审核签名自动失效。
