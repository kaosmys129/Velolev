## 一、本次全面重构内容

1. **废弃违规与虚假宣传**：
   - 全面清除未经证实的认证宣称（彻底剔除任何 CE、ISO 9001 虚假背书）；
   - 彻底删除所有裸露货币符号（`$`、`€`、`£`、`¥`），统一采用 B2B 商业宏观叙述与 ROI 测算模型；
   - 纠正作业人员编制宣称：严格标定为两名作业人员协同作业（`two-person operation` / `two workers`），严禁宣传单人独立高空施工；
   - 纠正历史陈旧品牌名：统一为 `volvet` 或通用工程品类术语（`portable light pole lifter` / `portable hydraulic pole lifter`）。

2. **锁定核心原子物理事实 (F001–F031)**：
   - 额定起升载荷：严格标定为 **300kg**（出厂垂直试验台 100% 核定，F002）；
   - 最大适配杆高：严格标定为 **12m**（覆盖 6m 至 12m 市政与太阳能路灯柱，F003）；
   - 系统工作动力：严格采用集成式 **24V DC 直流电池系统**（F004）；
   - 整机分体总重：严格标定为 **85kg**（液压主机 45kg + 电气控制箱 40kg，F008）；
   - 底板法兰跨度：通用长腰孔底板兼容分布圆直径（P.C.D.）**180-260mm**（F015）；
   - 基础地脚螺栓：兼容 **M16 至 M24** 锚栓（标配 M16/M18/M20/M22 紧固附件各四套，F016）；
   - 质检防坠机制：800mm 垂直液压行程搭载机械安全销，出厂 100% 实施 24 小时保压测试（F020）。

3. **落地 On-Page SEO、三级梯度 CTA 与权威行业标准**：
   - 篇首统一标配 `> ### 📌 Key Takeaways for Project Engineers` 核心要点卡片；
   - 正文自然植入三级梯度转化漏斗：
     - **Top-Funnel (轻量探索)**：下载 12m 规格书与安装手册 PDF（`/resources/`）；
     - **Mid-Funnel (方案测算)**：嵌入吊车租赁 ROI 计算器测算卡片（`/tools/roi-calculator/`）；
     - **Bottom-Funnel (采购决策)**：嵌入法兰图纸 24h 免费核验与出厂私密报价入口（`/quote/`）；
   - 严格引证国际权威标准（EEAT）：
     - `OSHA 1926 Subpart CC (29 CFR 1926.1408)`（吊车临电与高空安全缓冲区）；
     - `ANSI/IES RP-8-18`（道路照明垂直对准与配光均匀度规范）；
     - `ASTM F1554 / ASTM A325`（地脚锚栓拉拔抗剪强度标准）；
     - `EN 40-3`（照明立柱抗侧风倾覆力矩结构验算）；
     - `IEEE 516`（临近带电线路最小安全作业距离）；
   - 篇末提供专业 FAQ 模块，并嵌入符合 Schema.org 的 `FAQPage` 结构化数据代码块。
